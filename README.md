# KMUTNB VC Volleyball

Club website using Google Apps Script, Google Sheets and Drive.

## Vercel

Import this repository with Framework Preset Other. No build command is required. Output Directory is dist (configured in vercel.json).

## Backend

Use dist/Code.gs in Google Apps Script. See dist/INSTALL.md. Keep the existing Spreadsheet and Drive settings. Backend updates require deploying a new Apps Script version.

Content and member data remain in Google Sheets and Drive; this repository contains application code only.
